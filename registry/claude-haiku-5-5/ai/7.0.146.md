## ai@7.0.146
- In ai@7, convertToModelMessages returns Promise<ModelMessage[]>; await it before passing as streamText `messages`: `messages: await convertToModelMessages(...)`.
- result.toUIMessageStreamResponse() is deprecated; use standalone `toUIMessageStream` and `createUIMessageStreamResponse` from 'ai' with `result.stream`.
- generateObject and streamObject are deprecated; use `generateText` / `streamText` with an `output` setting instead.
- result.totalUsage is deprecated; use `result.usage` instead.
- result.response is deprecated; use `result.finalStep.response` instead (e.g. `finalStep.response.messages`).
- toUIMessageStream takes an options object, not a bare stream: call toUIMessageStream({ stream, tools?, ...UIMessageStreamOptions }) where stream is the result's stream (AsyncIterableStream<TextStreamPart>).

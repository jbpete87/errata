## ai@7.0.146
- Do not pass convertToModelMessages(...) directly as streamText's messages; it returns Promise<ModelMessage[]>. Await it first.
- Deprecated: result.toUIMessageStreamResponse(). Use standalone toUIMessageStream and createUIMessageStreamResponse helpers from 'ai' with result.stream.
- Deprecated: generateObject. Use generateText with an output setting instead.
- Deprecated: streamObject. Use streamText with an output setting instead.
- Deprecated: result.totalUsage. Use usage instead.
- Deprecated: result.response. Use finalStep.response instead.
- Wrong: passing a bare AsyncIterableStream to toUIMessageStream. Right: toUIMessageStream({ stream }), since its parameter requires an object with a stream: ReadableStream property.

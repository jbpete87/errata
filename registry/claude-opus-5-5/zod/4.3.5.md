## zod@4.3.5
- In zod@4.3.5 the string-method format checks `z.string().email()`, `.url()`, `.uuid()` are deprecated; use the top-level `z.email()`, `z.url()`, `z.uuid()` instead (message/params argument still accepted).
- `ZodObject.passthrough()` is deprecated in zod@4.3.5; use `.loose()` on the object schema or build it with `z.looseObject()` instead.
